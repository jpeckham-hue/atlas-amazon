# Atlas Amazon Agent Entry Point

## Project state first

**Before planning, coding, reviewing, or reporting project status, read `PROJECT_STATE.md`.**

Use it as the navigation index for authoritative architecture/planning sources, current priorities, blockers, and verified milestones. Verify referenced files and commits before making status claims, and distinguish pushed GitHub state from local/uncommitted Codex work.

When a canonical roadmap/current-state source, branch responsibility, major priority, blocker, or significant milestone changes, update `PROJECT_STATE.md` in the same change set.

If `PROJECT_STATE.md` is missing, stale, or contradicts its linked sources, flag the problem immediately and verify source truth before continuing.
